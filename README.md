# Community Library Lending System

ITS203 Object-Oriented Design and Programming

A C# Windows Forms project for a small community library lending system.

## Current development stage

The repository starts with the project foundation and OOP model classes. Planned functionality includes:

- Book catalogue management
- Library member management
- Book lending and returns
- Search and filtering
- Overdue loan detection
- Library summary
- SQLite data storage
- Input validation and exception handling

## OOP model

- `LibraryItem` is the base abstract class.
- `Book` inherits from `LibraryItem`.
- `Member` represents a library member.
- `Loan` represents a lending transaction.
